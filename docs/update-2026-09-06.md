# 2026-09-06 渲染兼容性更新

本次更新修正 OBJ 贴图错位与光照偏暗，并提供适合 MMD 导出模型的简单显示预设，保持基础软件光栅化实现。

- 修正纹理采样的 V 方向：OBJ 使用左下角 UV 原点，TGA 加载后内部行序从顶部开始，采样使用 `1-v`，解决脸部、服装等图集区域错位。
- Flat、Gouraud 和 Phong 的基色在光照计算前从 sRGB 转为线性值，输出前再编码为 sRGB，改善中间调；法线和 UV 调试输出保持数值直映。
- 新增 `--mmd` 预设：环境光设为 0.62，关闭高光、阴影与背面剔除，改善皮肤塑料感及薄片显示。它是现有参数组合，不是完整的 MMD Toon Shader。参数按顺序解析，可在预设后使用 `--ambient` 调整亮度。
- 仓库加入 `obj/luotianyi` 素材目录，并让无参数运行、CMake 生成的 VS 工程、原生 VS 工程都默认渲染这套素材。

## 使用

```powershell
.\renderer.exe obj\luotianyi\luotianyi.obj --mmd --ssaa 2 -o output.png
```

直接运行 `renderer.exe` 时，会使用 `obj\luotianyi\luotianyi.obj` 和 `--mmd` 预设输出 `output.png`。也可以继续传入其他 OBJ 路径覆盖默认模型。

仓库中的洛天依素材包含 OBJ、MTL 和三张 TGA 贴图；MTL 中各材质通过 `map_Kd` 指向对应贴图。

## 验证与范围

使用 `build.bat` 成功构建，并对本地洛天依模型分阶段渲染：UV 修复、颜色空间修复、柔和光照预设。核对了脸部、衣服和鞋袜贴图位置及暗部亮度。构建仍有原有线段绘制代码的数值转换警告。

当前没有实现透明度混合、完整 Toon 材质或 PMX 骨骼加载。双线性纹理过滤及 SSAA 降采样仍在编码后的颜色上进行，颜色处理属于基础改进。UV 与颜色空间修复会影响其他模型，`--mmd` 预设仅在显式启用时生效。
